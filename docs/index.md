# Astro-star Docs

Astro-star is an open-source personal site theme based on Astro 5, featuring six pages: Home, About, Blog, Notes, Projects, and Links. It bundles comments, RSS, Sitemap, and in-site search into a maintainable, long-lasting site.

All docs are hand-written (the author dislikes AI-generated docs). If any AI edits are made, they will be noted at the top of the page.

The docs are organized into four sections:

| Section                           | Content                                                      |
| --------------------------------- | ------------------------------------------------------------ |
| [Theme](./theme/overview)         | Theme overview and feature highlights                        |
| [Deploy](./deploy/deploy)         | Deployment from scratch, comments (Waline), search (Algolia) |
| [Creation](./creation/content)    | Configuration, content authoring, friend links               |
| [Develop](./develop/contribution) | Custom development and contribution guide                    |
