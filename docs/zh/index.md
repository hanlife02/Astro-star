# Astro-star 文档

Astro-star 是一个基于 Astro 5 的开源个人站点主题，包含“首页、关于、博文、手记、项目、友链”六个页面，把评论、RSS、Sitemap 和站内搜索放到一个可长期维护的站点里。

文档均为手写(鉴于作者也不喜欢看 AI 文档，所以坚持手写精要的文档)，如后续使用 AI 编辑则会在文档最上方标出。

文档按四部分组织：

| 章节                           | 内容                                              |
| ------------------------------ | ------------------------------------------------- |
| [主题](./theme/overview)       | 主题总览、特性介绍                                |
| [部署](./deploy/deploy)        | 从零开始部署、接入评论(waline)、接入搜索(algolia) |
| [创作](./creation/content)     | 修改配置、创作文章、修改友链                      |
| [开发](./develop/contribution) | 客制开发、如何贡献                                |
