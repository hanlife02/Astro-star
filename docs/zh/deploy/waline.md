# Waline 接入

## 部署 waline

你可以参考[waline 部署](https://waline.js.org/guide/deploy/)

## 设置 Secrets

在 [部署流程第 5 步 - 设置 Actions secrets](./deploy#_5-设置-actions-secrets) 中，添加以下 Secret：

| Secrets                  | 说明              |
| ------------------------ | ----------------- |
| PUBLIC_WALINE_SERVER_URL | waline 部署的地址 |

之后重新构建即可
